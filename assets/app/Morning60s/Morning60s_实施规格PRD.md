# Morning60s — 实施规格 PRD（执行版）

> 本文档为**可执行规格**：只写「如何做出这个 App」——页面、字号、流程、逻辑均按此一步步实现。

## 一、产品与命名

- **App 名称**：Morning60s
- **一句话**：在「5:00 + 3 小时未用手机」后首次亮屏时弹出「醒了吗？起床啦！」并开始计时，按用户选择与行为给出奖励或等待下次唤醒。

---

## 二、核心逻辑（严格按流程图）

以下为**唯一**逻辑标准，实现时必须一致。

### 2.1 触发条件

| 条件 | 说明 |
|------|------|
| 时间 | 用户设定的起床时间窗口起点之后（例如 5:00 之后） |
| 静置 | 手机连续未使用 ≥ 3 小时（用加速度等判断） |
| 动作 | **该时间窗口内**，用户**首次**点亮手机屏幕（拿起 + 解锁） |

满足后 → 进入 2.2。

### 2.2 首次弹窗与计时

手机锁屏界面跳出来的弹窗：「准备好起床了吗？」
a. 用户若选择是，出现弹窗文案。
- **弹窗文案**：标题「醒了吗？起床啦！」；副文案可说明「60 秒起床，获得双倍奖励！」。
- **行为**：弹窗出现时**即开始 5 分钟倒计时**（流程图：跳出弹窗并且开始计时）。
app:
- **1个按钮**：
  - **按下按钮**：「是的，我起来啦！」→ 走 **2.3 路径一（是）**
  - **没按按钮**→ 走 **2.4 路径二（否）**

b. 用户选择「否」（误判 / 非起床时点）

- 等待**下一次屏幕唤醒**；
- **本次不要求 3 小时静置**（因为可能是回笼觉，流程图明确：此时不需要三小时间隔）。

### 2.3 路径一：用户选择「是」（确实要起床）
- **用户立刻起床**：
  1. 用户点击 **「已起床」** → **倒计时暂停**；
  2. 用户**拍摄自己站着、穿着拖鞋的样子**（拍照验证）；
  3. 验证通过 → **倒计时停止，用户获得奖励**（60 秒内完成 = 双倍，否则 = 标准）。

### 2.4 路径二：
- **赖床玩手机**：用户切出 App 玩手机时，**灵动岛显示倒计时**（Live Activity），直到用户决定起床。

## 三、页面清单与可执行规范（极简版 · 先跑通）

**原则**：每个页面只保留核心功能，一大按钮 + 一句话，无多余装饰，便于先让流程走通。

---

### 3.1 今日 / 首页（Wake Screen）

| 项目 | 规格 |
|------|------|
| 入口 | Tab 第 1 项，图标 `sun.max.fill`，标题「今日」 |
| 布局 | **极简**：中央一句主文案 + 一个全屏视觉焦点的大按钮，无图标/无渐变/无装饰条 |
| 主文案 | **一句**：「醒了吗？起床啦！」— 标题，Bold，约 28pt，主色 #FF8C42，居中 |
| 副文案 | 可选一行：「60 秒内完成 = 双倍奖励」— 正文 15pt，次要色，居中（可先不展示，先跑通再加） |
| 主按钮 | **「是的，我起来啦！」** — 全宽、大圆角、背景 #FF8C42、白字、headline；点击即**开始 5 分钟倒计时**并进入挑战页（3.3）。也作为「从系统弹窗选“是”后进入 App」的落地页主操作。 |
| 背景 | 纯色 #FFF8E7，无渐变 |
| 联调 | 未做唤醒检测前：进入 App 即见此页，点按钮直接进挑战页。 |

### 3.2 系统确认弹窗（按流程图触发，先于/或伴随进入 App）

| 项目 | 规格 |
|------|------|
| 触发 | 满足 2.1 后：时间窗口内 + 静置 ≥3 小时 + 首次亮屏/解锁 |
| 标题 | 「准备好起床了吗？」 |
| 正文 | 可留空或一句：「点「是」将开始 5 分钟计时。」 |
| 主按钮 | 「是」— 打开/切回 App，进入今日页（3.1），**同时后台即开始 5 分钟倒计时**；今日页上用户点「是的，我起来啦！」进入挑战页。 |
| 次按钮 | 「再睡会儿」— 不开始计时，关闭弹窗；下次唤醒**不要求** 3 小时间隔（2.4）。 |

**逻辑对照**：弹窗选「是」= 同意被叫醒，**此时就启动 5 分钟倒计时**；进入 App 后首页只做一件事：一个大按钮「是的，我起来啦！」进入挑战页（路径一/二在挑战页及之后区分）。

### 3.3 挑战进行中页（Challenge Screen）

| 项目 | 规格 |
|------|------|
| 出现时机 | 在今日页点击「是的，我起来啦！」后全屏展示（此时 5 分钟倒计时已在跑） |
| 布局 | **极简**：一句提示 + 大倒计时 + 一个主按钮，无进度条/无步数（可后续加） |
| 主文案 | **一句**：「快去离开床铺吧！」— 标题 2，semibold，居中 |
| 倒计时 | 大号数字 `MM:SS`，56pt Bold；≤60 秒用 #06D6A0，>60 秒用 #FF8C42 |
| 主按钮 | **「已起床」** — 点击后**倒计时暂停**，进入拍照验证页（3.4） |
| 灵动岛 | Live Activity 与当前倒计时同步，切出 App 时显示（路径二：赖床玩手机时看灵动岛） |
| 背景 | 纯色 #FFF8E7 |

### 3.4 拍照验证页（Photo Verification）

| 项目 | 规格 |
|------|------|
| 出现时机 | 挑战页点击「已起床」、倒计时已暂停后 |
| 布局 | **极简**：一句说明 + 相机/拍照区 + 一个提交按钮 |
| 说明 | **一句**：「请拍摄自己站着、穿着拖鞋的样子」— 标题 3，居中 |
| 相机 | 系统相机UI，拍一张 |
| 主按钮 | 「提交验证」— 提交后：通过 → 停止倒计时、进奖励页（3.5）；失败可重拍。MVP 可「拍照即通过」。 |

### 3.5 盲盒 / 奖励页（Reward Screen）

| 项目 | 规格 |
|------|------|
| 出现时机 | 拍照验证通过后全屏展示 |
| 布局 | **极简**：一句标题 + 本次获得内容（列表可极简为一行或几行文字）+ 一个按钮 |
| 标题 | **一句**：「挑战成功！」— Bold，色 #06D6A0 |
| 内容 | 「你获得了…」+ 角色名/稀有度（可先文字列表，无动效）（最好先给我画一个小面包） |
| 主按钮 | 「查看我的餐桌」或「完成」— 关闭本页回到 Tab |

### 3.6 收藏页（Collection Screen）

| 项目 | 规格 |
|------|------|
| Tab | 第 2 项，图标 `leaf.fill`，标题「收藏」 |
| 布局 | **极简**：标题「早餐收藏」+ 收集进度一句（如「X / 20」）+ 简单网格/列表，无多余卡片样式 |
| 内容 | 已收集：emoji + 名称；未收集：灰色占位。无底部「图鉴」「商店」等（MVP 不做）。 |

### 3.7 设置页（Settings Screen）

| 项目 | 规格 |
|------|------|
| Tab | 第 3 项，图标 `gearshape.fill`，标题「设置」 |
| 布局 | 系统 Form，仅保留必要项 |
| 必选项 | 起床时间窗口（开始/结束时间）；离床验证：拍照开关（默认开）；通知开关；隐私一句「数据仅存本地」。 |
| 无 | 步数、图鉴、商店等 MVP 不做。 |

## 四、视觉与全局规范

### 4.1 配色（与 PRD 一致）

| 用途 | 色值 | 名称 |
|------|------|------|
| 主色/强调 | #FF8C42 | AccentOrange |
| 辅助 | #FFD166 | AccentYellow |
| 背景 | #FFF8E7 | CreamBackground |
| 成功 | #06D6A0 | AccentGreen |

### 4.2 字体

- **大标题/主标题**：SF Rounded，Bold，34pt / 28pt  
- **标题 2/3**：SF Rounded 或 SF Pro，Semibold，22pt / 20pt  
- **正文/说明**：SF Pro，Regular，15–17pt  
- **Caption**：SF Pro，12pt  

### 4.3 动画

- 页面过渡、弹窗：≤ 0.3s，ease-in-out  
- 盲盒开启：0.5–1s 可接受  

### 4.4 数据与权限

- 持久化：**Core Data**（iOS 16.1+），本地 SQLite，不依赖 .xcdatamodeld 时可代码构建模型。  
- 权限文案（Info.plist）：通知、运动与健身（若用步数）、位置（若用位置辅助）、相机（拍照验证）。

## 五、执行顺序建议（按此一步一步做）

1. **项目与命名**  
   - 新建或复用工程，App 名、Bundle 名、显示名统一为 **Morning60s**；最低版本 iOS 16.1。

2. **数据层**  
   - Core Data 模型（纯代码或 .xcdatamodeld）：UserSettings（起床时间窗口等）、挑战记录、早餐角色与收集状态；PersistenceController 单例，不依赖 bundle 内 .momd。

3. **今日页 + 弹窗**  
   - 实现极简今日页（3.1）：一句「醒了吗？起床啦！」+ 大按钮「是的，我起来啦！」→ 进入挑战页；系统弹窗（3.2）标题「准备好起床了吗？」，选「是」即开始 5 分钟倒计时并进入 App。未做唤醒检测前，打开 App 即见今日页，点按钮直接进挑战页联调。

4. **唤醒检测（无手表方案）**  
   - 在设定时间窗口内、手机静置 ≥3 小时后，首次亮屏/解锁时触发弹窗；实现「再睡会儿」后下次唤醒不要求 3 小时间隔（流程图 2.4）。

5. **挑战页 + 倒计时 + 灵动岛**  
   - 5 分钟倒计时；「已起床」按钮点击后暂停倒计时；Live Activity 灵动岛与当前倒计时同步（3.3）。

6. **拍照验证**  
   - 点击「已起床」后进入拍照页（3.4）；拍照并提交后视为通过 → 停止倒计时、发奖励并进入奖励页（严格对应流程图 2.3）。

7. **奖励页 + 盲盒逻辑**  
   - 奖励页（3.5）；60 秒内完成抽 2 次、否则 1 次；20 个基础角色、稀有度权重（见原 PRD）。

8. **收藏页 + 设置页**  
   - 收藏页（3.6）、设置页（3.7）；设置项写回 UserSettings 与本地存储。

9. **联调与边界**  
   - 真机测试唤醒检测、倒计时、拍照流程、灵动岛；处理权限被拒、无相机等情况。

## 六、流程图与逻辑对照表

| 流程图节点 | 实现位置 |
|------------|----------|
| 5:00+ 时间窗口、静置 ≥3 小时、首次亮屏/解锁 | 唤醒检测服务 → 触发系统弹窗 |
| 弹窗「准备好起床了吗？」选「是」 | 系统 Alert 主按钮 → **此时即开始 5 分钟倒计时**，打开/切回 App 到今日页 |
| 弹窗选「否」 | 「再睡会儿」→ 不开始计时，下次唤醒不要求 3 小时间隔 |
| 今日页唯一主操作：「是的，我起来啦！」 | 今日页（3.1）大按钮 → 进入挑战页（3.3），倒计时已在跑 |
| 路径一：用户立刻起床 → 点「已起床」 | 挑战页主按钮 → 倒计时暂停 → 进入拍照验证（3.4） |
| 拍照通过 → 倒计时停止、发奖 | 验证通过 → 结束 Live Activity、发奖、跳奖励页（3.5） |
| 路径二：赖床玩手机 | 用户不点「已起床」即切出 App → 灵动岛显示倒计时（Live Activity） |
